# nosok-the-game

Интерактивный веб-проект и мини-игра бренда NOSOK.

## Использование нейросетевых инструментов

В ходе работы над проектом нейросетевые инструменты использовались как вспомогательная технологическая поддержка, а не как самостоятельный автор проекта.

Они применялись для следующих задач:

- генерация и редактура отдельных фрагментов кода;
- поиск и локализация ошибок;
- подготовка и редактирование текстовых материалов;
- помощь в адаптации проекта под GitHub Pages;
- помощь в очистке и перестройке окружения после отказа от Vite и связанных зависимостей;
- поддержка при точечных правках интерфейса и пользовательских сценариев.

Использованные инструменты и роли:

- `Codex` использовался для генерации, правки и рефакторинга кода, а также для технической помощи при публикации и поддержке проекта;
- `Kiro CLI` и `OpenClaw` применялись как дополнительные инструменты для работы с кодом вне дома;
- `Claude` использовался в роли менеджера и координатора задач;
- `Figma MCP` использовался как специализированный навык для работы с дизайн-контекстом и перевода визуальных решений в реализацию.

Отдельно нейросетевые инструменты выступали в роли «ментора по коду»: они помогали разбирать архитектурные решения, объясняли возможные технические выборы, сравнивали подходы и использовались как обучающая поддержка в процессе разработки.

Итоговые решения по структуре проекта, выбору механик, содержанию и финальной интеграции принимались автором проекта.
